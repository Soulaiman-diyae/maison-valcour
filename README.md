# Maison Valcour

Demo website for a fictional luxury car dealership in Paris. French by default, with an FR/EN switch.

Plain HTML, CSS and JavaScript — no build step. Open `index.html` or serve the folder with any static server.

- `index.html` — page markup (French text by default)
- `css/styles.css` — styles, including the mobile layout
- `js/data.js` — the car inventory and photo links
- `js/i18n.js` — French and English text
- `js/app.js` — filters, sorting, details panel, booking form, language switch, mobile menu

## Photos

Car photos are loaded from Wikimedia Commons under their Creative Commons licences. Photographer credits are listed in the site footer ("Crédits photo") and under each photo in the details panel.

The dealership, prices and vehicles are fictional; the booking form sends nothing.
